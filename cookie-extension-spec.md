# ТЗ: Safari-расширение, которое отклоняет cookie-баннеры

## Что делаем

Расширение для Safari на macOS. Оно автоматически отклоняет cookie-баннеры на сайтах (нажимает «Отклонить всё» / снимает необязательные согласия) и показывает аккуратный тост внизу по центру: «Куки отклонены · Изменить».

Личный проект, без публикации в App Store. Подпись — бесплатный Personal Team (Apple ID) в Xcode.

**Перед началом работы:** прочитай это ТЗ целиком, предложи план по фазам и дождись подтверждения. Работаем по фазам, после каждой — проверка руками.

## Стек

- **Safari Web Extension** (Manifest V3), обёрнутый в macOS-приложение через Xcode (шаблон «Safari Extension App» или `xcrun safari-web-extension-converter` для готовой папки расширения).
- **Движок отказа от кук:** [`@duckduckgo/autoconsent`](https://github.com/duckduckgo/autoconsent) (npm). Не писать правила для консент-платформ самостоятельно. Изучи README и пример расширения в репозитории autoconsent (папка с аддоном) и интегрируй по их схеме: content script + background, обмен сообщениями, режим opt-out.
- **Сборка JS:** простой бандлер (esbuild), чтобы собрать autoconsent и наш код в файлы расширения. Без фреймворков в content script.
- **Хранилище:** `browser.storage.local` для вайтлиста и счётчика, `browser.storage.session` (или память background) для «уже показывали тост на этом сайте в этой сессии».
- macOS-приложение-контейнер минимальное: одно окно с текстом «Включи расширение в Safari → Настройки → Расширения» и кнопкой, открывающей настройки Safari (стандартный код из шаблона Xcode).

## Поведение

### Отказ от кук
- На каждой странице autoconsent пытается найти известную CMP и выполнить opt-out (отказ от всех необязательных кук).
- Если сайт в вайтлисте — ничего не делаем.
- Тост показываем **только** при успешном opt-out (событие из autoconsent о том, что отказ выполнен). Если баннера не было или отказ не удался — тихо.

### Частота тоста
- Первый успешный отказ на домене за сессию браузера → **полный тост** (кружок → пилюля с текстом).
- Повторные отказы на том же домене в этой сессии → **только кружок** с иконкой: появляется и исчезает, без раскрытия (тихое «сработало»).
- Ключ — eTLD+1 (например, `news.example.co.uk` и `www.example.co.uk` считаются одним сайтом) — если просто сделать, иначе hostname.

### Поповер «Изменить»
По клику на пилюлю открывается маленький поповер над ней, два действия:
1. **Показать баннер сайта** — один раз пропустить автоотказ для этого домена и перезагрузить страницу (баннер сайта появится, пользователь выберет сам).
2. **Не трогать этот сайт** — добавить домен в вайтлист навсегда и перезагрузить страницу.

После действия текст в пилюле на ~2 с меняется на подтверждение («Баннер показан» / «Сайт в исключениях»), затем тост уходит.

### Попап расширения (иконка в тулбаре) — фаза 3
- Переключатель «Работать на этом сайте» (вайтлист текущего домена).
- Счётчик «Отклонено баннеров: N» за всё время.
- Список сайтов в исключениях с возможностью удалить.

## Тост: визуал и анимация

**Критично:** тост рендерится внутри чужих страниц. Весь UI тоста — в **Shadow DOM** (closed или open) внутри одного хост-элемента, добавленного в `document.documentElement`. Все стили — внутри shadow root, с явным сбросом (`all: initial` на корне), явным `font-family` (`-apple-system, BlinkMacSystemFont, sans-serif`), `font-size`, `line-height`. Хост-элемент: `position: fixed`, `z-index: 2147483647`, `pointer-events: none` у контейнера и `pointer-events: auto` только у пилюли и поповера.

### Геометрия
- Позиция: по центру снизу, отступ снизу 24px.
- Пилюля: высота 36px, `border-radius: 999px`, фон почти чёрный (`#1c1c1e`), текст белый, 13px.
- В состоянии «кружок» ширина = высота = 36px.
- Содержимое: иконка печеньки 16px (SVG, inline), слева отступ 10px (иконка ровно по центру кружка), справа 16px, gap 8px.
- Текст: «Куки отклонены», разделитель «·» (opacity 0.5), «Изменить» (weight 500, подчёркнут, `text-underline-offset: 3px`).
- Иконка прижата к левому краю контейнера содержимого, поэтому при раскрытии пилюли в обе стороны от центра она сама уезжает влево.
- Лёгкая тень допустима: `0 4px 16px rgba(0,0,0,.18)`.

### Последовательность появления
| Шаг | Что происходит | Длительность | Кривая |
|---|---|---|---|
| 1 | Кружок 36px: `scale 0 → 1`, opacity 0 → 1 | 320 мс | `cubic-bezier(0.34, 1.9, 0.64, 1)` |
| 1a | Иконка внутри: `scale .4 rotate(-40deg) → scale 1 rotate(0)`, opacity 0 → 1, старт с задержкой 80 мс | 384 мс | `cubic-bezier(0.34, 2.2, 0.64, 1)` |
| 2 | Пауза кружка | 250 мс | — |
| 3 | Ширина 36px → ширина содержимого | 450 мс | `cubic-bezier(0.34, 1.6, 0.64, 1)` (лёгкий овершут) |
| 3a | Текст: opacity 0 → 1, `translateX(-6px) → 0`, задержка 140 мс от начала шага 3 | 220 / 280 мс | ease-out |

Пилюля центрирована через `left: 50%; transform: translateX(-50%)`, поэтому растёт в обе стороны. Анимировать ширину можно через `width` (элемент один, это допустимо) или через `clip-path`/`scaleX` с контр-скейлом содержимого — на выбор, главное без дёрганья текста.

### Удержание
- 3000 мс.
- При наведении на пилюлю таймер **на паузе**, после ухода курсора — продолжается с остатка.
- Пока открыт поповер — таймер стоит.

### Исчезновение
| Шаг | Что происходит | Длительность | Кривая |
|---|---|---|---|
| 1 | Текст: opacity → 0, `translateX(-6px)` | 150 мс | ease-in |
| 2 | Ширина → 36px (обратно в кружок), старт через 60 мс | 300 мс | `cubic-bezier(0.5, 0, 0.75, 0)` |
| 3 | Кружок: `scale → .6`, opacity → 0; иконка `rotate(20deg) scale(.6)` | 180 мс | ease-in |

После завершения — удалить хост-элемент из DOM.

### Режим «только кружок» (повторный показ)
Шаги 1 и 1a появления → удержание 900 мс → шаг 3 исчезновения.

### Reduced motion
Если `prefers-reduced-motion: reduce`: сразу полная пилюля, только fade-in 250 мс, удержание как обычно, fade-out 300 мс. Никаких scale/width/rotate.

### Поповер
- Над пилюлей, отступ 12px, по центру.
- Фон белый (в тёмной теме системы — `#2c2c2e`), радиус 12px, padding 6px, тонкая рамка, тень.
- Пункты: иконка 16px + текст 13px, padding 8px 10px, hover-фон.
- Появление: opacity + `translateY(6px) → 0`, 180 мс.
- Закрывается по клику вне, по Esc, после выбора действия.

### Доступность
- Хост тоста с `role="status"`, `aria-live="polite"`.
- Пилюля фокусируема, Enter/Space открывают поповер.

## Фазы

1. **Каркас.** Xcode-проект Safari Web Extension, сборка, расширение включается в Safari, content script пишет в консоль домен страницы. Проверка: лог виден в Web Inspector.
2. **Движок.** Подключить autoconsent, opt-out работает на тестовых сайтах (баннеры исчезают, отказ выполнен). Пока без UI, только логи.
3. **Тост.** Shadow DOM, вся анимация, логика «полный тост / только кружок», поповер с двумя действиями, вайтлист в storage.
4. **Попап.** Переключатель для сайта, счётчик, список исключений.

## Тестирование
- Список сайтов с разными CMP (OneTrust, Cookiebot, Didomi, Quantcast, Usercentrics) — подобрать европейские новостные и магазинные сайты. Баннеры часто показываются только посетителям из ЕС/UK — тестировать с соответствующим VPN.
- Проверить: сайт без баннера (тоста нет), сайт с баннером (полный тост), повторный заход (только кружок), вайтлист (баннер остаётся), reduced motion, тёмная/светлая тема сайта (тост выглядит одинаково), сайт с агрессивным CSS (тост не ломается).

## Не делаем
- Блокировку рекламы и трекеров.
- Свои правила для CMP (только autoconsent).
- Публикацию в App Store.
